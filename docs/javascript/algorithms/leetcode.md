## 26. 删除排序数组中的重复项

题意：
1. 就地修改
2. 要求空间占用 O(1)，不能用中间数组

思路：
1. 双指针覆写，慢指针在元素不重复时才移动
	  - 重点不是 nums 修改，而是输出 length。结合 length，可以作一次 slice，给出 nums
1. 倒序遍历，当元素重复时，删除当前项
	  - 正序剪切，会影响 i。倒序减切掉一个元素，i--，不影响待处理元素（身后）

## 70. 爬楼梯

转化：到达前一步楼梯的方法数+前两步方法数

- **递归实现：**
    
    - **优点：** 直接利用问题的递推关系，思路直观。
    - **缺点：** 时间复杂度是指数级的 O(2n)O(2^n)O(2n)，因为存在大量的重复计算，效率较低，可能导致栈溢出。
- **带缓存的递归（动态规划）：**
    
    - **优点：** 通过记录每一步的结果，可以避免重复计算，将时间复杂度降到 O(n)O(n)O(n)。
    - **缺点：** 需要额外的空间来存储每一步的结果，空间复杂度是 O(n)O(n)O(n)。
- **空间优化的动态规划：**
    
    - **优点：** 只需要两个变量来存储前两步的结果，可以将空间复杂度降到 O(1)O(1)O(1)。
    - **缺点：** 实现稍微复杂一些，但在大多数情况下是最优的解决方案。


动态规划记录每个子问题的解来避免重复计算，通常用于优化递归解决方案。

## 三数之和

1. 暴力 O n^3
2. 双指针 如何做到不重复（有序 + 有两个数字不重复，第三个数字一定不重复，不会出现 [1, 2]，[2, 1]，每个数字开头的解要穷举）

```js
function threeSum(nums, target = 0) {
    // let res = []
    let res: number[][] = []
    nums.sort((a, b) => a - b)
    for (let i = 0; i < nums.length; i++) {
        if (i > 0 && nums[i] === nums[i - 1]) continue
        let l = i + 1
        let r = nums.length - 1
        while(l < r) {
            let other = target - nums[i]
            let sum = nums[l] + nums[r]
            if (sum > other) r--
            if (sum < other) l++
            if (sum === other) {
                res.push([nums[i], nums[l], nums[r]])
                if (l < r && nums[l + 1] === nums[l]) { // 下一个值与当前值相同时，多跳一步
                    l+=2
                } else {
                    l++
                }
            }
        }
    }

    return res
}



console.log(threeSum([-1, -2, 2, -2, 0, 4, 1]))
console.log(threeSum([0, 0, 0, 0]))
```
